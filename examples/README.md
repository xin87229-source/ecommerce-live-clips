# 最小技术样例与真实素材要求

这个目录提供示例说明，实际测试文件由 [tools/smoke_test.py](../tools/smoke_test.py) 在自己的私有工作区生成。它不携带商家视频、人物图像、第三方音频、模型、字体或 Python 环境。

## 用四秒样例检查安装

先完成 [依赖安装](../docs/dependencies.md) 和工作区 `init` / `doctor`。在 PowerShell 中填写同一组真实路径：

```powershell
$Install = 'D:\eclip\project'
$Python = 'D:\eclip\envs\trial-01\Scripts\python.exe'
$Workspace = 'D:\eclip\workspaces\shop-a'
& $Python "$Install\tools\smoke_test.py" --workspace "$Workspace" --name install-01
```

若要同时验证已下载的本地模型能初始化，另选新名称：

```powershell
& $Python "$Install\tools\smoke_test.py" --workspace "$Workspace" --name install-02 --load-model
```

输出只写入 `工作区/outputs/install-smoke/名称/`。名称只允许 1–64 个字母、数字、短横线或下划线；目录已存在就拒绝运行，失败目录也不覆盖。失败时先读 `report.json` 和 `media.log`，修复环境后使用新名称再测。

| 文件 | 用途 |
| --- | --- |
| `pattern.mp4` | FFmpeg 程序生成的四秒测试图案与 440 Hz 测试音，无真人或直播原声 |
| `video.mp4` | 1080×1920、30 fps CFR、H.264/AAC；全程显示“技术测试 / 不是直播原话” |
| `subtitle.srt`、`subtitle.ass` | 固定技术标签，不能当作机器识别或人工核准的直播字幕 |
| `cover.png` | 从测试视频第 2 秒提取的真实帧，不是商品实拍封面 |
| `report.json` | 规格、完整解码、逐帧时间、文件哈希和模型检查结果 |
| `media.log` | 本机技术命令和错误记录 |
| `fonts/` | 从已配置字体复制的渲染资源，仅留在私有工作区，不随源码候选分发 |

`technical_passed` 表示生成和媒体技术检查通过：4 秒、1080×1920、30 fps、120 帧、H.264/AAC、音画时间与全量解码均须符合。自己打开 `video.mp4`，确认汉字清晰、没有方框、图案连续变化且能听到测试音。报告不会把运行成功自动写成连续观看或实际试听通过。

不传 `--load-model` 时，`model_check.status` 为 `not_checked`。传入后只以 CPU/int8 和 `local_files_only=True` 初始化已配置模型，不联网、不下载、不转写测试音；模型加载成功仍不证明中文转写准确。该工具不创建或修改业务任务卡、商品审核、采用证据、人工验收或平台状态。

生成图案和测试音没有使用第三方素材；所用程序、字体仍各有其权利和许可。项目原创源码采用 [MIT](../LICENSE)，本说明不为生成物或第三方字体另行指定 CC0 等许可。

## 还缺一份可公开的真实女装样例

技术样例不能说明运营能完成真实业务。当前还需要有明确公开权利的中文女装原片、商品参考图和原声，才能另做可复现的真实示例。

可自行拍摄一份最小素材，建议这样准备：

- **范围**：一款真实女装、一次连续拍摄，30–60 秒；可确认同款的原片区间至少 20 秒，保留完整句子和自然停顿。不要用已经剪好或生成的成片代替原片。
- **画面**：竖屏 1080×1920、30 fps、SDR、方形像素；单视频流、单音轨。光线稳定，清楚呈现同款的全身/正侧面、腰部或袖口与面料近景。素材没有提供的细节不靠文字补足。
- **声音**：安静环境、正常语速中文原声，推荐 AAC、48 kHz；不叠第三方背景音乐。讲两三个能实际看到或有资料支持的特点，避免未经证实的价格、库存、功效与材质结论。
- **参考图**：同一件实物的正面及一个可辨认细节，保持原图；由权利人提供，不能从商家详情页随意抓图。能证明来源的原文件单独保留。
- **人工记录**：实际听过的人提供逐字稿、听不清处和时间点；记录本人真正听看的范围。逐字稿用于核对，不自动作为 ASR 已准确的结论。
- **版本**：保留完整原片、原图、SHA-256、实际拍摄信息和独立工作区。修改版另存，来源映射可追溯。

公开前要有具体到这份文件及使用范围的权利记录：谁拥有视频、照片和口播内容；出镜者是否同意其肖像和声音作为可下载的示例公开；画面是否含第三方音乐、图片、标志或个人资料。授权应说清是否允许下载、修改、再分发及商用，并确认提供者确有权作此授权。缺项就继续作为私有素材，不加入公共包。

许可由素材权利人与项目所有者另行决定，不能因为“是自己拍的”就替所有出镜者或第三方宣布任意再分发许可。取得可公开素材后，仍须独立完成同款、原话、最终速度连续听看和版本绑定；不能沿用内部 A4 的审核状态。
