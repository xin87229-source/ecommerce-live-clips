# AI 女装直播切片 Skill：项目任务与规划

确认日期：2026-10-28。此定位替代先前把业务项目进度、网站同步、获客和首笔收费服务列入本项目当前任务的安排；历史技术验收事实保留。

## 当前目标

交付一个独立、免费、可通过 GitHub 获取的女装直播切片 Skill。借鉴成熟业务流程的判断方法，在本仓库形成可复用的通用流程、程序、说明和验证；使用者提供自己的原片、商品参考和独立工作区。

当前交付单位是完整仓库＋项目内 `ecommerce-live-clips` Skill。代码和文档按现有 MIT 许可公开；Skill 免费不表示使用者选择的 AI 宿主或第三方服务免费。本项目当前不内置收费服务或自动云端听音调用。

## 项目边界

| 项目/能力 | 本项目如何处理 |
| --- | --- |
| 雅乔切片 Skill | 仅为业务流程经验来源，独立维护；不直接使用其私有入口、配置或验收记录 |
| 雅乔切片策略网站及其他历史项目网站 | 均不参与；不部署、不保存、不回读网站作为本项目交付门槛 |
| 独立 Skill | 当前唯一开发重点：本地原片到可核验成片、字幕、封面、文案及质量记录 |
| 本地审片与预览页面 | 保留已有能力，属于本地交付物，不是网站建设或托管 |
| 平台发布、账号、挂车、排期 | 当前独立 Skill 不提供，不把其他项目的双账号制作/提交算入进度 |
| 可下载开源软件 | 后期阶段，待 Skill 成熟后另行立项；现有 CLI 是 Skill 的执行工具，不是已交付的软件产品 |
| 收费机制 | 后期软件规划，不在当前 Skill 中开发支付、订阅、授权限制或收费服务销售流程 |

## 当前事实基线

- 唯一公开仓库：<https://github.com/xin87229-source/ecommerce-live-clips>。2026-10-28 核验为 Public，默认分支 `main`。
- 程序版本：`0.1.0-rc.16`，仍是预发布候选；本轮按14类扩充公共术语及词义，保持知识参考与保守纠正规则分离，转写保持原设置。
- 已有统一委托、原片窗口、转写、剪辑、字幕、封面文案、待审/已审交付和恢复能力。同一商家三款真实内容确认及正式本地交付已记录。
- 外部运营、另一独立商家、全新电脑和更广女装覆盖尚未通过。本仓库没有已验证的百炼音频理解接入；其他项目接入记录不能继承。
- 实际验证结果及每次检查范围只在 [验证状态](release-status.md)维护；本页列任务和验收条件，不另造完成百分比。
