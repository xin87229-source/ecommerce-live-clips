更新：2026-10-28；当前为 `0.1.0-rc.16` 的420词、14类公共词库。服务不同女装商家的理解与字幕处理，不代表已测得跨商家识别覆盖率。

`apparel.terms` 按上述类别分组，每项保存 `term`（写法）和 `meaning`（含义或易混边界）。旧字符串词条仍可读取；公共维护使用带释义格式。校验允许最多1000个不重复词，限制字段、单词和释义长度，拒绝控制符。这个容量是程序边界，不是覆盖率目标。

```json
{"term": "里布", "meaning": "用于衣服里层的布料；不等同用于支撑造型的衬布。"}
```

Skill 按当前商品和问题读取相关类别，不必一次加载全部词条。纤维与成分、织物组织、版型、工艺分别理解：羊毛与羊绒、真丝与仿真丝、混纺与交织不能互换；天丝是品牌名称，不能当成所有莱赛尔或莫代尔的默认改名。颜色营销名没有由词语直接确定的统一色号。

这些释义是项目自行编写的简释与使用边界，不是标准原文或标准逐条全文核验。基础参考包括官方[《服装术语》信息页](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=18B68FAAA29D37829F87D824F9002170)、[中国丝绸博物馆对织物基本组织的介绍](https://www.chinasilkmuseum.com/gskt/info_319.aspx?itemid=30898)、[兰精的天丝品牌纤维说明](https://www.tencel.com/zh-cn/fibers)、[苏州市场监管部门的号型说明](https://scjgj.suzhou.gov.cn/szqts/bmzs/201801/41c320bfa8034aec971447041a347cda.shtml)及[GINETEX洗护符号说明](https://www.ginetex.net/gb/labelling/care-symbols.asp)。口播俗称、风格和营销颜色另作语境解释，不冒充标准名称；洗护与服务词不构成对具体商品的建议或承诺。

## 纠正规则：知识词多不等于自动替换多

`apparel.rules` 与 `terms` 分开，程序只按显式规则修改显示字幕。当前6条文字规则是原4条加同一已确认语境的两种逗号写法：

- “塔兔→獭兔”“容毛→绒毛”作为女装术语拼写规范化。
- 仅在“让你创生”这一完整短语中改为“让你穿上身”；不全局修改“创生”。
- “背后或者显肥”及中、英文逗号变体中改为“背厚”，原标点保留；正常的“看一下背后”不改。

价格、数量、尺码值、材质比例、库存、功效、品牌和款号不由词库猜补。词条可以含数字，例如“九分裤”，但数字保护仍约束纠正规则。保留“不掉毛／掉毛”“不显胖／显胖”“不支持退换／支持退换”的区别；不删否定词，不把普通口语强行改成书面语。

新增规则应来自已核对的具体错词和语境，并同时验证命中例、正常词反例、否定关系、数字及原文留痕。仅有同音、词义相近或词条收录不足以建立全局替换。术语规范化不等于实际听审，也不证明实物材质。

沿用本地模型与既有参数，不新增依赖或付费接口。此前把整份词表直接作为模型提示的真实试跑出现新错字和句界变化，因此该方式没有启用；本轮扩词不改变原ASR及缓存身份。`basic` 不套用女装规则，通用 `replacements` 保持默认空。

## 商家资料：只供当前工作区参考

品牌、款号、SKU、专属款名和颜色名、主播自己的叫法，由Codex依据用户已提供资料记录在当前商家工作区。需要时可使用 `private-context/apparel-terms.json`；没有资料不创建空文件，也不要求用户手写JSON。每条至少说明词语、含义、适用商品或范围，以及可追溯的用户确认或商品资料出处。

该文件供Skill读取，不是程序自动合并的第二词典；不会自动加载成替换规则，也不提交到公共GitHub。换商家不继承这些记录。需要改字幕时仍走现有本地反馈或人工纠错入口；正式字幕中已有显式人工纠错优先，该句不再叠加词库规范化。

## 原文、时间与验收

先处理明确规则和用户已确认词语，同一文件和保留范围不反复询问。其余影响结果的疑点结合前后文和实际听音能力集中处理，仍不确定再提供一次带时间的问题。局部词语、同款范围与整片验收分别留证，不将局部确认扩大成整片或全场通过。

可复用旧ASR预览生成新的术语修正版，不为同音改字重跑整段模型。原转写、旧包和原始反馈保持原样；记录原文、改词、规则、来源句及词库指纹。升级代码或词库后保留旧检查结果，但不能把其当作新版通过；统一入口使用新 `run_id`。

显示文字变化的短句沿用整句起止时间，旧机器词时间只作证据，不借给新文字分页。若修正长句仍超出两行，需重新转写或换完整短句；未改词的长句继续复用已有词时分页。正式交付链也记录词库辅助模块的程序指纹。

整体待审状态和正式交付所需确认继续按 [完整演练](local-rehearsal.md) 与 [已审稿交付](reviewed-delivery.md) 执行。验收扩库效果时分别记录术语错误、正确词误改、剩余人工疑点；不能仅凭词条数量宣布识别准确率提高。
