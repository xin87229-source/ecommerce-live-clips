# 按商品与素材选择剪法

本说明服务女装各子类目和风格；支持范围是策略设计，不等于每一类都已用真实素材验收。商品识别、实际听看和用户最终确认分别记录。策略程序提供选镜需求，不是视觉识别模型。

## 先明确主商品

从用户给出的名称、商品参考和实际画面建立本次商品描述：主商品类别、可见轮廓、用户指定风格、实际讲到的特点、可用展示、尚未确认的信息。穿搭中的裤子、内搭或外套不自动成为本次销售对象；同场颜色相近也不代表同款。商品名可帮助选择策略，不能证明面料、弹性、价格或同款。

读取 `pipeline/apparel_strategy.py` 的策略输出，作为本次观察清单。上衣、裤装、连衣裙、半身裙、外套和套装共用制作链；其他女装和未知类别使用通用展示策略。未知风格保留用户原词，由实际商品和素材决定表达，不强行归入相似标签。

## 选段时把声音和画面放在一起判断

每个候选需要回答四件事：说了什么；实际看见什么；为何用于这条视频；有哪些缺项。记录真实窗口及时间、已查看帧或连续片段、商品相关区域、展示动作及判断来源。静态抽帧只能证明该帧可见内容，不能证明完整动作或全段同款。

- 口播讲版型，优先寻找能看到对应轮廓的画面；讲面料时寻找原片已有的细节或演示。没有证据时删去这个主张或改选别段，不能补写卖点。
- 一个视觉上吸引人的片段未必能独立成片。留足语义前提和原句，不把机器断句当作最佳剪口；句内截取继续使用既有核词证据规则。
- 纯上身展示可以承担效果证明，不能把 ASR 空白当成无人说话。非同期画面继续记录独立声画来源，避开明显口型矛盾。
- 含换款、串款、价格、尺码或疑词的材料先保留风险。在同一素材内能找到清楚替代段时优先换段；不能靠删除风险标记获得通过。

## 根据表达决定结构和外观

少量可选结构足够：效果先行→细节依据；穿着问题→实际演示；完整搭配→目标商品特点；单个连贯展示。先选择证据完整的主线，再决定顺序，不按固定段数拼凑。无需每条都出现所有结构角色。

风格主要影响节奏、字幕密度、封面排版和镜头停留。通勤风可以清楚呈现轮廓与搭配，休闲风可以保留自然动作；这只是可选表达，不意味着相应商品必然有特定人群、面料或功效。用户指定风格优先，素材与其不符时说明冲突。

速度服从听感和动作完整性，沿用项目允许的范围。时长由完整表达决定，不把某条样片的秒数、速度或定格参数写成通用硬规则。保留全身或商品关键部位；无法判断安全裁切时保留原画面并适配画幅，不随意放大。

用户的时长目标按变速后的实际成片计算。例如约一分钟通常需要约75–90秒的有效原声，仍须按实际速度、剪口及尾定格重新计算。短窗口内容不足就查相邻同款窗口，不能用重复画面或无关口播补秒数。强调字幕优先选本条实际原话中的部位、结构、搭配词；材质与效果存在疑点时不通过大字突出为卖点。完整演练的词表与视觉检查见[演练说明](local-rehearsal.md#时长重点词和衔接)。

## 交付前自检与有限修订

先执行程序的时长、帧率、解码、来源和字幕时间检查，再实际看关键帧、连续片段并在具备能力时听原声。逐项区分检查结果，技术正常不能推出商品正确或字幕已核词。

能够机械判断的问题可重新生成新版本：尺寸不合适时采用保留全画面的适配；字幕拥挤时调整字号或布局；源段重复时重新选择有实质差异的证据。不得为了排版改写原话，也不得以自动重试代替事实确认。每轮只修有明确原因的项，最多两轮自主修订；仍有问题时保留版本和具体阻塞，不无限重试。

输出新旧版本、实际变动、证据范围与待审问题。若改了剪口、速度、声画或字幕，对应范围及最终整片听看重新核验；只改文案可复用未变化的视频，但重新核对文案事实和交付清单。

## 真实测试覆盖

私有工作区中为每次运行记录：素材与哈希、原片范围、目标商品及依据、可见类别、指定风格、环境、产物版本、自动完成的阶段、介入原因、修改次数和工时。至少区分以下结果：

| 结果 | 证明什么 |
| --- | --- |
| 策略单元测试通过 | 类别回退、观察依据与输入处理按预期工作 |
| 真实原片自动生成预览 | 本机真实媒体与制作入口已执行 |
| 准确核词与商品审核通过 | 本次指定范围有真实内容判断 |
| 正式交付且最终验收通过 | 本次素材完成业务闭环 |
| 外部运营独立完成并换素材复用 | 对应用户与素材范围内具备可用性 |

使用本机素材是内部验证；不能当作另一商家或外部用户试用。测试表没有覆盖的类别、风格、电脑保持未验证。公开包只含方法和不含隐私的测试代码，真实测试素材及记录不分发。
