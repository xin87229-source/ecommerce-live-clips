# 三人外部试用方案

本文是执行方案与空白记录模板。是否已经完成试用，只在 [release-status.md](release-status.md) 更新，不以本页存在、招募文案写好或候选包打好作为完成证据。试用包的发放须在许可、白名单和隐私检查确认后进行；本项目没有自动邀请、上传或联系他人的功能。

## 这轮只验证什么

Windows x64、Python 3.12、中文单场单款，使用完整项目与项目内 Skill，面向会用 Codex 操作本地文件的女装电商运营。保留 `basic`，但首轮不以非女装通过作为门槛；跨品类、其他系统、其他 AI 宿主另轮验证。软件界面、账号体系和平台自动发布均不在本轮范围。

目标是验证外部运营首次配置后，能否一次委托 Codex 用自己的原片完成制作，正确处理需要真实核实的内容，并在换素材时复用。分别记录自动生成预览、正式文件交付和内容验收；不能把三者合为一个成功率。女装子类目和风格按实际素材登记，未测范围保留未验证。

## 人选与验收

选择 3 位实际承担女装内容工作的运营，至少 1 位来自与当前内部测试不同的独立女装商家。为便于比较，使用同一个已记录版本与源码清单哈希；不得把三次内部重复运行算作三位试用者。

优先让试用素材覆盖不同女装子类目（上衣、裤装、裙装、外套）与不同风格，同一人可追加第二类素材。类目不足时列出缺口，不把画面中出现的搭配单品当作主商品覆盖。另记录每次人工介入的原因：安装、工具执行、内容事实、审美修订或最终验收，以决定后续应优化的环节。

| 编号 | 要求 | 主要任务 |
| --- | --- | --- |
| T01 | 会用 Codex，但未参与开发 | 从完整包和说明开始，独立安装与制作第一条 |
| T02 | 另一家独立女装商家 | 用自己有权使用的真实原片、商品参考与独立工作区完成首条 |
| T03 | 实际运营 | 完成首条；其中至少 1 位试用者随后换一份新原片再次使用 |

本轮通过条件须同时满足：

1. 3 人均留下安装与任务记录，至少覆盖另一家独立女装商家；未完成者和原因也保留。
2. 至少 2 人不依靠维护者远程修改源码，按文档完成安装、真实素材试作、可播放粗剪/听审材料及本地交付。允许按文档改工作区配置、用 AI 执行步骤和提出问题；每次求助须记录。维护者代做、远程接管或直接修改源码的结果可作问题定位，不能计入这 2 人。
3. 至少 1 人换一份不同的新原片（也可同时换目标商品）再建任务，复用同一程序完成第二次制作，记录第二次人工工时。更名重跑同一素材、复制旧成片、复用旧同款/字幕通过结论都不算复用成功。
4. 实际同款核对、字幕核词、最终速度连续听看与用户确认分别记录；若原片不足或确实听不清，可以得到零条或待审稿，但该次不能计作“真实业务闭环已完成”。
5. 无未解释的来源/哈希/版本冲突；任务状态与真实输出相符。

若未达到，不扩大承诺；归类问题，修订文档或程序，换版本后重测受影响步骤。所有人失败都可能说明安装和任务流程仍不适合当前人群，不能把它归咎于“用户不会用 AI”。

## 发给试用者的一页说明

准备 Windows x64 电脑、会操作本地文件的 Codex、自己有权使用的中文女装原片、准确商品参考图、独立磁盘空间及能实际听看的人。不要上传账号密码、商家表格或未经授权原片到反馈渠道。

1. 保存候选版本与文件哈希，解压完整项目，按 [依赖安装](dependencies.md) 新建虚拟环境；不要复制别人的环境。
2. 按 [快速开始](quickstart.md) 使用 `apparel` 初始化自己的独立工作区，完成 `doctor`。
3. 先选 30–60 秒真实原片窗口做 `test`，实际抽窗与本地转写。机器字幕错误不要猜改。
4. 对照商品参考看首中末和完整窗口，回听原声。用听审卡反馈原话、听不清处与时间点，再制作真实粗剪。
5. 查看成片、字幕、封面和质量记录。播放完整成片并听全片原声；未做的项明确留待审，不以技术检查代替。
6. 关闭后用 `status` 接续，填下面记录。承担复用任务的人另换新素材建立新任务，保留第一条。

遇到阻塞先保存完整报错与当前阶段，不重新安装全部软件，不改任务卡跳过门禁。实际反馈渠道由维护者在发包时提供；当前未设公开 URL，不应把素材发到猜测的地址。

## 维护者如何回收结果

先收安装记录、版本、错误、必要的脱敏截图和用户原话。确实需要片段才能排查时，先界定时间范围与用途，再取得素材提供者的授权；默认不收整场原片、店铺账号或客户资料。

三人表汇总时分别报告“安装完成”“可审阅产物”“真实业务闭环”“换素材复用”，每项写分子/分母、失败原因和人工帮助。收到“喜欢这个版本”只证明偏好，不能自动转成逐字听审和最终验收。真实数据出来前，不填节时、成片率或转化率。

## 招募文案草稿

> 招募 3 位会使用 Codex 的女装电商运营，试用一套 Windows 本地直播切片 Skill。它需要完整项目、Python、FFmpeg 和本地转写模型，一次先处理一场中文直播中的一款商品。
>
> 你需要准备自己有权使用的原片和商品参考，按说明安装并做一条可审阅视频，实际核对同款、字幕和最终听感。我们希望至少有一位来自另一家女装商家，并有一位愿意换一份新素材再做一次。
>
> 这轮重点记录安装耗时、求助与失败、改片次数和第二次操作工时。当前仍在验证中，不承诺全自动、不承诺节时或成交，不做平台上传与发布。原片和账号不需要随反馈上传；具体反馈方式与试用条款在发包时说明。

这是未发送的招募草稿。发放前补真实版本、反馈方式、支持范围和素材约定；不填虚构链接。
