## 2026-10-28 片尾定格检查修订

此前片尾检查的失败已定位为测试误报：H.264 CRF18 是有损编码，克隆同一画面后解码像素仍可能有微小差异。原测试只检查1.8～2.2秒的尾部，而实际定格从1.6秒开始；也未与最后内容帧比较，因此错误黑色定格反而可能通过旧断言。

同一生产滤镜只更换无损编码后，最后内容帧及全部18个定格帧在1080×1920下的帧摘要完全一致；正常MP4的微小压缩差与黑尾、错误帧和继续运动的对照分别检查。修订验证方法，不改变生产编码或放宽内容审核，旧制作与审核绑定保留。实际回归范围及环境限制见[本次记录](tasks/2026-10-28-hold-validation.md)。

首版不支持自动商品识别、无人审核字幕、自动发布、挂车、排期或跨平台安装承诺；输入限单视频流、单原声音轨、SDR、方形像素。原声不清、错款或证据不足时保留待审/零条结果。

当前按[项目规划](project-plan.md)推进免费 Skill 的[发行准备](release-preparation.md)、[首次使用交接](service-handoff.md)和新电脑验证；人选到位后恢复 [免费外部试用](external-trial.md)，不得倒填成功记录。网站、收费服务、软件开发不列入当前任务。安装见 [依赖说明](dependencies.md) 和 [首次使用](quickstart.md)，审片见 [人工审核](human-review.md)。未完成项不能被本地测试数量或品质愿景替代。
