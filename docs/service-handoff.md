# 安装与首条制作协助：范围和交接单

这是一份可复制到独立工作区填写的服务范围草案，不是已成交订单，也不代表外部用户已能独立操作。适合会用 Codex、有权使用本地中文女装原片的 Windows 运营。先看[当前验证范围](release-status.md)；没有实际听审人时，最多交付待审稿，不能承诺正式内容验收。

## 首单只做一个明确范围

建议先约定一台 Windows 电脑、一个商家工作区、一场原片中的一款商品和一条目标成片。目标时长由有效口播决定；约一分钟是可选要求，不保证任意素材都能凑足。

| 阶段 | 交付物 | 完成依据 |
| --- | --- | --- |
| 环境配置 | 实际工具/模型/字体路径、依赖版本、独立工作区 | 环境检查、模型真实加载、短窗转写、中文字幕真实输出分别留证 |
| 首条制作 | 选款说明、原片映射、带字幕视频、真实帧封面、文案、原速问题 | 文件能打开，来源可追溯，疑词与同款状态如实保留 |
| 内容验收 | 对应版本和时间范围的原始反馈 | 实际完整听看、核词和同款确认；缺任一项则仍待审 |
| 正式交付 | 新目录中的视频、SRT/ASS、双封面、文案、质量与变化记录 | 通用交付检查通过；新的画面/封面另查，旧证据保留 |
| 使用交接 | 恢复方法、路径说明、已知问题、换素材操作说明 | 客户实际关闭后恢复；另换素材独立完成才记“复用通过” |

安装、短窗试作、完整待审稿、正式内容验收、独立复用分别记状态。若委托只含安装，就按环境阶段验收，不写成整条业务已经跑通。

## 出问题时如何交接

- 不支持的媒体或环境：保留报错与输入特征，停止依赖该条件的制作；先约定换输入、适配或结束范围，不偷偷放宽校验。
- 原话或同款不能确认：交付原速问题卡及待审版本，写明还缺谁确认什么；不收费承诺“无须听审”。
- 需要改源码：记录具体修复及新候选指纹，旧包保留。由维护者改过源码的任务不能算“外部用户无需帮助独立完成”。
- 中断后恢复：先检查任务状态、当前版本和运行进程，沿原工作区接续；不重置记录、不覆盖源片。`auto status` 若报告 `ERROR`，记录具体 `failed_stage`、`error` 和已完成阶段；`request-validation` 表示本次请求准备失败，不能拿旧“交付就绪”代替本次结果。修正尚未执行的输入后复用原请求；源码或已完成输入变化则保留旧记录，按新运行处理。准确命令见[统一入口](one-click.md)。
- 最终仍无法达到约定阶段：列已完成与未完成项，按开始前的范围和失败约定处理；程序成功不替代客户的内容确认。

各约定服务阶段可分别报价，但不在没有范围和真实工时的情况下预填价格。先验证一次安装配置与交接服务，重复需求明确后再考虑付费模板或软件功能。源码仍按项目 MIT 许可使用，服务不改变其许可。
