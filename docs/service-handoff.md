# 免费首次使用与交接记录

本页保留旧文件路径以兼容现有链接，替代原收费服务交接方案。当前只验证独立免费 Skill 的首次使用，不报价、不收款、不设置付费任务；软件和收费留到[后期规划](project-plan.md)。是否通过以[验证状态](release-status.md)为准。

## 一次验证范围

一台 Windows 电脑、一个独立商家工作区、一场有权使用的中文原片中的一款商品。目标时长服从真实完整表达，不保证任意素材凑足约一分钟。实际核词、同款与最终听看分别记录，没有能力或证据时交付待审稿。

| 阶段 | 输出 | 完成依据 |
| --- | --- | --- |
| 环境 | 工具、模型、字体及依赖配置 | doctor、模型加载、短窗转写和中文字幕输出分别留证 |
| 首条制作 | 字幕视频、双封面、文案、来源映射、原速问题 | 可打开且来源可追溯，疑词和审核状态如实保留 |
| 内容验收 | 绑定实际版本与范围的原始反馈 | 完整听看、原速核词、字幕和同款确认分别记录 |
| 正式交付 | 视频、字幕、封面、文案、质量记录 | 现有交付检查通过；新画面/封面另查，旧证据保留 |
| 接续与复用 | 恢复记录、第二份不同素材任务 | 先核状态再恢复；换素材独立完成才算复用通过 |

## 异常接续

不支持的媒体或环境保留错误，先定位缺项，不放宽校验。原话或同款不能确认时提供短原速问题与时间点，不写假通过。维护者改源码或代做过的任务可以用于排错，不能记作外部独立成功。

中断后先检查版本、工作区、进程和 `auto status`。`ERROR` 要保留 `failed_stage`、`error` 及已完成步骤；`request-validation` 表示最新请求准备失败，旧交付不能代替最新结果。修正未执行的输入后沿原请求恢复；源码或已完成输入变更则保留旧记录，按[统一入口](one-click.md)处理，不覆盖旧状态。

公开问题用 [GitHub Issues](https://github.com/xin87229-source/ecommerce-live-clips/issues)，只提供版本、阶段、预期/实际结果和脱敏错误。安装、远程控制和素材传输须按当次范围处理，不需要店铺密码或平台登录。免费 Skill 不包含 AI 宿主或第三方服务的费用承诺，也不自动调用收费服务。
